# bytemux/homebrew-tap

Homebrew casks for [btmx-focus](https://github.com/bytemux/btmx-focus), a
native macOS menu-bar focus timer.

```sh
brew install bytemux/tap/btmx-focus
```

btmx-focus isn't notarized; the cask clears the quarantine flag so macOS
opens it without asking. `scripts/release.sh` in btmx-focus updates the cask
on each release.
